# Portfolio de Gabriel Megroian

Site statique (HTML, CSS, JavaScript), publié avec GitHub Pages.

- `index.html` : la page
- `css/` : styles et transitions
- `js/data.js` : tout le contenu (projets, compétences, parcours, contact) ; c'est le fichier à modifier pour mettre le site à jour
- `js/` : interactions, simulation de l'accueil, visuels des projets
